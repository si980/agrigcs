// AgriGCS Hardware Configuration Header

// Target: ESP32-WROOM-32 (IDF 5.1 / Arduino 2.x)

#pragma once

#include <Arduino.h>


#define PIN_SOIL_ANALOG 34

#define PIN_DHT22_DATA 4

#define ADC_RESOLUTION 12


void setupHarnessBus() {

analogReadResolution(12);

analogSetAttenuation(ADC_11db);

pinMode(PIN_SOIL_ANALOG, INPUT);

pinMode(PIN_DHT22_DATA, INPUT_PULLUP);

Serial.begin(115200);

}

electrical_services
3.3V Logic Level Safety

ESP32 GPIO pins are not 5V tolerant. Directly wiring 5V sensor outputs without a bidirectional level shifter will permanently damage ADC channels.

sensors
Capacitive vs Resistive Probes

Corrosion-resistant capacitive probes operate via frequency shift through FR-4 solder mask, eliminating soil electrolysis and DC lead oxidation.

shield
Ground Loop & Noise Isolation

Keep wire harnesses under 1.5 meters or add a 100nF ceramic decoupling capacitor across the ADC input to dampen inductive spikes in agricultural mesh networks.
